## 2025-12-31 - Initial Security Enhancement: `.gitignore`
**Vulnerability:** Lack of a `.gitignore` file.
**Learning:** An empty repository, while not having active vulnerabilities, is missing foundational security measures. Adding a `.gitignore` is a crucial first step to prevent accidental commitment of sensitive files like `.env` or `node_modules`.
**Prevention:** Always ensure a comprehensive `.gitignore` file is present in any new project.
